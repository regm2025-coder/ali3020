# مِيعاد — إدارة الاجتماعات والمهام

واجهة أولية عربية (RTL) لتطبيق مِيعاد، مبنية باستخدام React وVite.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## بناء نسخة الإنتاج

```bash
npm run build
npm run preview
```

## الحالة الحالية

- واجهة لوحة تحكم عربية متجاوبة مع الهاتف.
- عرض الاجتماعات والمهام التجريبية.
- إضافة مهمة وتغيير حالتها داخل الواجهة.
- البيانات تجريبية ومحفوظة في حالة الواجهة فقط؛ لا يوجد تسجيل دخول أو اتصال بقاعدة بيانات حتى الآن.
- لا تضع مفاتيح Supabase أو أي أسرار في ملفات الواجهة أو المستودع العام.

## الخطوات التالية

مراجعة الواجهة، ثم تصميم وربط قاعدة بيانات Supabase وسياسات الصلاحيات بعد موافقة صاحب المشروع على SQL.
